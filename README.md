# ToDo List

## Descrição

O **ToDo List** é um projeto simples de uma lista de tarefas, desenvolvido como parte do desafio técnico de desenvolvimento front-end para estágio da Artifício T.I..

### Contexto do Desafio
Desenvolver uma aplicação web simples para gerenciamento de tarefas pessoais ("To-Do List"). O objetivo é criar uma interface funcional onde o usuário possa organizar seus afazeres diários.

---

## Requisitos Funcionais
- Adicionar Tarefa: Um campo de texto e um botão para incluir uma nova tarefa na lista.
- Listar Tarefas: Exibir todas as tarefas cadastradas na tela.
- Concluir/Editar: Permitir marcar uma tarefa como concluída ou alterar o texto dela.
- Excluir: Um botão para remover uma tarefa da lista.
- Persistência (Opcional/Bônus): Caso deseje, utilize o localStorage para que as tarefas salvas persistam mesmo após atualizar a página.

---
